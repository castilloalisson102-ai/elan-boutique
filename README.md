# elan-boutique

Tienda elegante de moda masculina y femenina con catálogo, filtros y carrito.

## Cómo abrir la app

1. Abre la carpeta del proyecto.
2. Ejecuta cualquiera de estas opciones:
   - Haz doble clic en `index.html`, o
   - En la terminal: `python -m http.server 8000`
3. Luego visita: `http://localhost:8000`

## Tecnologías

- HTML5
- CSS3
- JavaScript vanilla

## Funcionalidades

- Landing premium para boutique
- Sección de mujer y hombre
- Catálogo con búsqueda y filtros
- Carrito de compras con cantidades
- Modal de detalle del producto
- Diseño responsive

## Personalización

Puedes cambiar colores, textos, productos y URLs de imágenes editando los archivos:
- `index.html`
- `styles.css`
- `app.js`
